# UniNotify-CKS222

A software solution designed to assist university students in managing their academic tasks efficiently.

## Repository purpose

This repository supports the **CKS222 Software Process and Life Cycle** group assignment. It holds the report source, process-analysis artefacts and evidence. It is **not** a software product; no application code is required.

## University project used for comparison

- Course code: **CCA103**
- Course name: **Systems Analysis and Design**
- Semester II, 2025/2026, Group 36
- Project title: **UniNotify: Assignment & Deadline Reminder System**
- Source: Report 1 (System Analysis) and Report 2 (System Design & Implementation)

This was a coursework assignment used as the university project comparison, as permitted by the lecturer's FAQ. Only Lim Chin Jiek and Gabriel Gan Heng Qing were in the original CCA103 group; the other three current members contribute through the CKS222 audit and expansion work.
